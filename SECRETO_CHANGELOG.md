# Secreto TV Manager changelog

This file describes this fork only. The entry below is prepared for release; it does not assert publication.
Original Tellyscope history remains in CHANGELOG.md, with its copyright and GPL-3.0 attribution preserved.

## 1.1.0 — in development

Integrates original Tellyscope v0.16.0 (including its v0.15.x changes).

- More reliable pairing, reconnects after port changes and dropped links, and VPN/offline guidance.
- Private DNS validation and rollback; history restores original app, launcher, DNS and animation settings.
- Signed-list verification and protection against unsigned replacement.
- Remote touchpad, streaming app picker, volume improvements and physical RTL D-pad directions.
- App-store shortcuts, app-state actions, save-picker fixes and Fire TV improvements.
- Expanded monitoring and an advanced shell with change confirmation and no automatic history undo.
- Secreto branding, eight languages, fork-only metadata updater, signing and legal materials retained.
- No Secreto Launcher download or promotion added.

## 1.0.0 — 2026-11-02

First SecretoTools / Mohamed LALAH release candidate based on Tellyscope.

- Secreto TV Manager identity, existing project icon and Ocean Blue presentation.
- Eight languages: English, Arabic (RTL), French, Spanish, Hindi, Japanese, Russian and Simplified Chinese.
- First-run Welcome branding and a compact About & developer dialog with official SecretofNet YouTube and Instagram links, website and fork source links.
- Original credits, GPL-3.0 and third-party notices remain accessible in About.
- Optional update checks use only official SecretoTVManager releases; missing releases have a graceful state. Update offers open a release page, with no automatic APK download or installation.
- Fork-specific reporting, sharing and release history.
- Existing TV tools retained: ADB discovery, pairing and connection, remote, debloat with undo, apps, files, tweaks and monitoring. This is inherited functionality, not a claim that SecretoTools authored the original implementation.

Validation covers builds, automated tests and simulated layouts. No new physical-device compatibility or end-to-end TV testing is asserted.
